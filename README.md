# starjar.me

Static website for **Star Jar**, a simple reward-jar app for iPhone by Michael Palhidai.

Hosted on GitHub Pages at https://starjar.me (custom domain via `CNAME`).

- `index.html` – landing page
- `support.html` – support & FAQ (App Store Support URL)
- `privacy.html` – privacy policy (App Store Privacy Policy URL)
- `404.html` – not-found page

Plain HTML/CSS, no build step. Fonts: Fredoka One and Nunito (SIL Open Font License, see `fonts/`).
